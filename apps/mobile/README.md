# Extensión móvil futura

Este directorio reserva el lugar de una envoltura Capacitor para Android e iOS.

No forma parte de la fase 1:

- No hay proyecto Capacitor.
- No hay directorios `android/` ni `ios/`.
- No se generan APK, AAB ni IPA.

La aplicación exigida es una PWA. Capacitor, si se aprueba más adelante, reutilizará `apps/web` y no sustituye el manifiesto, el Service Worker ni el despliegue web. La decisión está en `docs/architecture/decisions/ADR-009-capacitor-future-extension.md`.
